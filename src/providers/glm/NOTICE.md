# CLIProxyAPI attribution

The GLM Coding Plan adapter follows the OpenAI-compatible provider execution
contract from CLIProxyAPI commit `acdace93`, specifically
`internal/runtime/executor/openai_compat_executor.go` and its translator
interfaces. This repository implements that contract in JavaScript and uses
Zhipu's dedicated Coding Plan endpoints. The upstream project's MIT license is
preserved in `CLIPROXYAPI-LICENSE.txt`.

Source: https://github.com/router-for-me/CLIProxyAPI/tree/acdace93
